# The AI Data Lab

Static research lab website. Open index.html to preview. See UPLOAD-GUIDE.md for GitHub Pages setup.

Research has two subsections: current-projects.html and selected-work.html. The latter contains the supplied selected publications, talks/workshops and research funding. A structured copy is in data/selected-work.json; the visible page is static HTML and must be updated when records change.

Homepage research photos are embedded for reliable display. See IMAGE-CREDITS.md for source and license details. No build step is required.
