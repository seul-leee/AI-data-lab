# Upload guide

Each HTML page now includes its own styles and images. A missing assets folder will no longer hide the logo or portraits.

1. Extract the ZIP.
2. Open index.html to preview the homepage, or people.html to preview People.
3. GitHub repository > Code > Add file > Upload files.
4. Upload all seven HTML files from inside the extracted AI-Data-Lab folder. Upload the other files too if desired; CSS and images are also embedded in the HTML.
5. Commit changes to main.
6. Settings > Pages > Deploy from a branch > main > / (root) > Save.

Portraits and student biographies are explicitly labeled examples, not actual members. Replace before public use. For later design changes, edit site.css and re-embed its contents in each page, or ask for an updated package.
